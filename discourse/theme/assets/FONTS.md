# Theme fonts

Inter (normal variable weight 100–900) and Playfair Display (normal variable
weight 400–900) are self-hosted Latin, Latin Extended and Vietnamese WOFF2
subsets. These are unchanged font files downloaded by this repository's
existing `next/font/google` production build, copied into the Discourse theme.
The matching `@font-face` unicode ranges are preserved from that build.

Both are distributed under SIL Open Font License 1.1. Copyright notices and
full licenses accompany the files in `Inter-OFL.txt` and
`Playfair-Display-OFL.txt`, retrieved from the official
[Inter](https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt) and
[Playfair Display](https://github.com/google/fonts/blob/main/ofl/playfairdisplay/OFL.txt)
directories on 2026-10-01. No font CDN is contacted by the member theme.
