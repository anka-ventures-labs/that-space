## Codebase Patterns

- **Next.js 14 App Router** — all pages in `src/app/`, all components in `src/components/`
- **Tailwind brand colors**: use `primary` (#5C3D2E), `secondary` (#C4A882), `cream` (#F5F0E8) — all defined in `tailwind.config.ts`. Can also use inline hex values (e.g. `text-[#5C3D2E]`) for one-offs.
- **Fonts**: `--font-playfair` (Playfair Display, headings) and `--font-inter` (Inter, body) CSS vars injected by `app/layout.tsx`. Use `font-[family-name:var(--font-playfair)]` in Tailwind classes.
- **Server vs Client Components**: pages default to Server Components. Mark `"use client"` only when needed (hooks, event handlers). Navbar is `"use client"` due to `usePathname`/`useState`.
- **Images**: logo at `/public/logo.jpg` → served as `/logo.jpg`. Always use `next/image` `<Image>` component.
- **Testing**: jest + @testing-library/react + jest-environment-jsdom. Config in `jest.config.ts` (uses `next/jest.js` createJestConfig). Tests in `__tests__/`. Mock `next/image` and `next/link` in tests. Run: `npm test`.
- **Typecheck**: `npx tsc --noEmit`. Must pass before committing.
- **Build**: `npm run build`. All 5 pages present in build output.
- **`@/` alias maps to `./src/*`** — `lib/` is at the project root, NOT inside `src/`. Use relative imports like `../../../../lib/forum-data` from `src/app/forum/[slug]/page.tsx`. Test files in `__tests__/` use `../lib/forum-data`.
- **`generateStaticParams()` must derive from data** — must import and map from the data file (not hardcode slugs) to keep static export in sync with data. Add explicit return type `{ slug: string }[]` to avoid TS errors.
- **`data-testid` on reply cards** — use `data-testid="reply-card"` on each reply `<div>` to allow `getAllByTestId("reply-card")` in tests; more reliable than filtering by role/text content when there are many similar elements.
